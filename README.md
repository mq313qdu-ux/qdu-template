# قالب QDU للاختبار التفاعلي

موقع ثابت (Static) يعمل على GitHub Pages بلا أي خادم أو SDK. الواجهة والمحرك مستقلان تمامًا عن المادة؛ المحتوى كله في ملفات JSON.

## البنية
```
index.html            الصفحة الوحيدة (مسارات نسبية فقط)
site.config.json      إعدادات الموقع (allowDemo, repoId, dataPath, protectContent)
css/theme.css         ثيم QDU الأصلي (لم يُعدَّل)   css/app.css  إضافات القالب
js/                   util · storage · core(منطق الدرجات/الإنجازات) · loader · tts · quiz · app
data/                 محتوى المادة الحقيقية (فارغ في القالب)
demo/                 بيانات تجريبية فقط (احذف المجلد من مواقع المواد النهائية)
tools/                validate-data.js و test-core.js و test-ui.js (للتطوير فقط)
```

## إنشاء مادة جديدة
انسخ القالب، افتح `data/` وعبّئ الملفات (لا تعدّل أي كود):

**subject.json** — `{"id":"radiology-2026","name":"اسم المادة","author":"اسم المُعِدّ","contentVersion":"1","enrichmentFiles":["enrichment.json"]}`
`id` إلزامي وفريد ويفصل تخزين تقدم الطالب عن بقية المواد.

**lectures.json** — `[{"id":"L1","title":"عنوان المحاضرة","icon":"📘"}]` (`order` و`number` اختياريان). رقم المحاضرة يُولَّد تلقائيًا من الترتيب ما لم تحدد `number`.

**questions.json** — `[{"id":"L1-Q001","lectureId":"L1","text":"...","options":["...","..."],"correct":2}]`
`correct` فهرس يبدأ من 0. لا تضع «A)» أو «1.» في النص (يُولَّدان تلقائيًا). **لا تغيّر `id` بعد النشر**؛ عند حذف سؤال تبقى نتائجه التاريخية محفوظة وتُعلَّم «محذوف».

**enrichment.json** (اختياري، ويمكن إضافة ملفات أخرى في `enrichmentFiles`):
`{"items":{"L1-Q001":{"translation":{"q":"...","options":["..."]},"explanation":"...","why":{"correct":"...","wrong":{"0":"..."}}}}}`
أي حقل ناقص يظهر للطالب كحالة «غير متوفر» دون اختلاق معلومات.

تحقق من البيانات قبل النشر: `node tools/validate-data.js data`

## النشر
1. احذف مجلد `demo/` وضع `"allowDemo": false` في `site.config.json`.
2. ارفع إلى GitHub Pages. التخزين المحلي مفصول بـ (المستودع + `subject.id`) فلا تختلط نتائج المواد.
3. للتجربة محليًا: `python -m http.server` ثم افتح `/?demo=1` (لا يعمل `file://` لأن المتصفح يمنع fetch).

## التخزين
مفتاح واحد لكل مادة: `qdu::<host/repo>::<subject.id>` (و`demo` للتجريبي) يحوي `{schema, state}`. الترقية عبر `Storage.migrations`. بيانات أحدث من الإصدار تُفتح للقراءة فقط، والبيانات التالفة تُنسخ احتياطيًا قبل البدء من جديد. سجل المحاولات المكتملة دائم ولا يُحذف.

## تعريفات
- **التغطية** = الأسئلة المختلفة التي حلّها الطالب ÷ أسئلة المحاضرة.
- **الإتقان** = الأسئلة التي آخر إجابة محفوظة عنها صحيحة ÷ أسئلة المحاضرة.
- **المقارنة** = أول وآخر اختبار *كامل* لنفس المحاضرة فقط (الاختبارات المخصصة والجزئية مستبعدة).

## اختصارات (غير معروضة في الواجهة)
↑/↓ تحديد · Space أو Ctrl منفردًا للتأكيد · → التالي · ← السابق. لا تعمل داخل الحقول ولا مع Ctrl/Alt/⌘.

## التلميح والقراءة
- زر التلميح يحذف خيارين خاطئين (3 مرات لكل اختبار، مرة لكل سؤال).
- القراءة الافتراضية: Google UK English Female (en-GB) · x0.8 · السؤال مع الاختيارات. تُعدَّل من أيقونة ⚙️ أعلى الاختبار، ويُستخدم أقرب صوت متاح إن لم يوجد.
